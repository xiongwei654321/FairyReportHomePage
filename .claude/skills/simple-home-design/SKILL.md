# 极简首页强制规范
1. 设计前置：先输出页面结构规划，确认后再写代码
2. 视觉：大面积留白，低饱和纯色，仅轻微柔和阴影，拒绝渐变背景
3. 排版：字重区分清晰，行高宽松，段落间距充足，不拥挤
4. 交互：仅hover轻微变色，无滚动动画、无复杂视差
5. 响应式：移动端优先，导航自动折叠汉堡菜单
6. 技术栈：Tailwind CSS v3 + 原生HTML/React二选一，代码轻量化无冗余
7. 无障碍：文字对比度达标，按钮可聚焦，适配手机缩放
8. 输出结构：导航→首屏→核心优势→客户→流程→咨询→页脚
